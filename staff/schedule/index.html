Schedule admin

The course schedule decides each student's start date and drop/add end date. Upload sections here, check the preview, and publish. Students only ever see published sections.

    1. Get the file ready

    Use a CSV file with these columns: Program, Term, Section, Start Date, and optionally End Date and Drop/Add Override. Program must match the program names on the student form exactly. Term looks like Spring 2027. Dates can be YYYY-MM-DD or M/D/YYYY. In Excel, choose Save as → CSV.
